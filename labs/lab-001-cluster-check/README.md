# 🏢 Step 1. 내 컴퓨터 속 미니 주방(클러스터와 노드) 둘러보기

축하합니다! `Step 0`에서 무전기(`kubectl`)를 성공적으로 손에 쥐셨군요! (복붙 경고 0회로 깔끔하게 통과하셨습니다 🎉)
이제 무전기를 켜서 **"우리 식당(클러스터) 상황실이 잘 돌아가고 있는지"**, 그리고 **"요리사를 배치할 주방 컴퓨터(노드)가 몇 대나 준비되어 있는지"** 첫 점검을 해봅시다!

---

## 📖 1교시: 오늘 배울 핵심 개념 2가지 + 마법의 동사 1가지

1. **[클러스터 (Cluster)](../../dictionary/concepts/concept-cluster.md)** = **'프랜차이즈 식당 지점 전체'**
   - 여러 대의 컴퓨터를 하나로 묶어 거대한 주방처럼 쓰는 단위입니다.
2. **[노드 (Node)](../../dictionary/concepts/concept-node.md)** = **'식당 안에 있는 실제 컴퓨터(주방 작업대) 1대'**
   - 앞으로 우리가 부를 요리사(컨테이너)들이 실제로 서서 일할 바닥(컴퓨터)입니다.
3. **[kubectl get](../../dictionary/commands/cmd-kubectl-get.md)** = **"목록 좀 표로 깔끔하게 가져와 봐!"**
   - 앞으로 쿠버네티스에서 가장 많이 치게 될 동사 1위입니다!

## ⌨️ 2교시: 손가락 근육 기억 (Typing Anatomy)

오늘 손가락에 익힐 문장은 총 3문장입니다! 눈으로 어순을 먼저 익혀보세요.

### ① 식당 상황실(Control Plane) 주소 확인하기
| 1어절 (무전기) | 2어절 (클러스터-정보) | 뜻 |
| :---: | :---: | :--- |
| `k` `u` `b` `e` `c` `t` `l` | `c` `l` `u` `s` `t` `e` `r` `-` `i` `n` `f` `o` | 지배인아, 우리 식당 전체(`cluster`) 정보(`info`) 좀 알려줘! *(가운데 빼기 `-` 하나로 연결!)* |

### ② 주방 컴퓨터(Node) 목록 가져오기 ⭐ (제일 중요!)
| 1어절 (무전기) | 2어절 (동사: 가져와라) | 3어절 (대상: 노드들) | 뜻 |
| :---: | :---: | :---: | :--- |
| `k` `u` `b` `e` `c` `t` `l` | `g` `e` `t` | `n` `o` `d` `e` `s` | 지배인아, 지금 켜져 있는 컴퓨터(`nodes`) 목록 좀 가져와 봐(`get`)! |

### ③ 주방 컴퓨터 목록을 '더 넓고 자세하게(`-o wide`)' 펼쳐보기
| 1~3어절 (기본 명령어) | 4어절 (출력 옵션) | 5어절 (넓게!) | 뜻 |
| :---: | :---: | :---: | :--- |
| `kubectl get nodes` | `-` `o` | `w` `i` `d` `e` | 방금 본 노드 목록을 출력(`-o`, output)할 때 숨겨진 정보(IP주소, 윈도우/리눅스 종류 등)까지 옆으로 넓게(`wide`) 펼쳐서 보여줘! |

> 💡 **어제의 복습 퀴즈!**: 왜 `--client`는 빼기 2개(`--`)였는데, 오늘 배우는 `-o`는 빼기가 1개(`-`)일까요?
> 👉 맞습니다! `o`(output의 약자)처럼 **알파벳 1글자짜리 짧은 옵션** 앞에는 빼기 기호를 **딱 1개(`-`)**만 붙이기 때문입니다!
