# 🛠️ Step 0-0. 내 컴퓨터에 쿠버네티스 실습장(주방) 차리기

아차! 무전기(`kubectl`)를 잡기 전에, **내 컴퓨터에 무전기와 미니 주방(쿠버네티스)이 설치되어 있는지**부터 확인하고 설치하는 안내서가 빠져 있었네요!
윈도우 PC에서 완전 초보자가 **가장 실패 없이, 가장 쉽게** 쿠버네티스를 설치하는 표준 방법을 안내해 드립니다.

---

## 🔍 1단계: 혹시 이미 깔려 있진 않을까? (1초 진단)

터미널 창(PowerShell)에 아래 명령어를 쳐서 내 컴퓨터 상태를 자동으로 점검해 보세요!

> **타이핑할 글자**: `.` `/` `c` `h` `e` `c` `k` 그리고 **엔터(Enter)!**

* 만약 **초록색 글씨로 `[통과]`**가 뜬다면? 이미 설치되어 있는 것입니다! 바로 `README.md`로 넘어가시면 됩니다.
* 만약 **빨간색 글씨로 `[미설치]`**가 뜬다면? 아래 **2단계**를 따라 설치해 주세요!

---

## 📦 2단계: 무엇을 설치해야 하나요? (딱 1개만 깔면 끝!)

옛날에는 도커 따로, 무전기(`kubectl`) 따로, 가상머신 따로 총 3~4개를 복잡하게 깔아야 했습니다.
하지만 요즘 윈도우에서는 **`Docker Desktop (도커 데스크탑)`** 프로그램 **딱 하나만 설치하면** 아래 3가지가 한 번에 다 깔립니다!

1. **Docker (도커)** : 밀키트 요리사 박스(컨테이너)를 만드는 도구
2. **kubectl (큐브컨트롤)** : 쿠버네티스에게 명령 내리는 무전기 (자동으로 같이 깔림!)
3. **내장 Kubernetes** : 체크박스 한 번만 클릭하면 켜지는 내 컴퓨터 속 미니 쿠버네티스 주방!

---

## 🚀 3단계: 설치 방법 (방법 A와 방법 B 중 편한 것 하나만 고르세요!)

### 방법 A. 마우스 클릭 없이 터미널에서 한 줄로 설치하기 (윈도우 공식 `winget` 활용 - 추천!)
윈도우 10/11에는 마이크로소프트 공식 앱 설치 도우미(`winget`)가 들어 있습니다.
터미널 창에 아래 글자를 직접 타이핑하고 엔터를 치면, 인터넷에서 공식 Docker Desktop을 알아서 찾아 설치해 줍니다!

| 순서 | 타이핑할 글자 | 설명 |
| :---: | :---: | :--- |
| **1어절** | `w` `i` `n` `g` `e` `t` | 윈도우 공식 프로그램 설치기 이름 (Win + Get) |
| *(띄어쓰기)* | *(스페이스바)* | - |
| **2어절** | `i` `n` `s` `t` `a` `l` `l` | 설치해라! |
| *(띄어쓰기)* | *(스페이스바)* | - |
| **3어절** | `D` `o` `c` `k` `e` `r` `.` `D` `o` `c` `k` `e` `r` `D` `e` `s` `k` `t` `o` `p` | 도커 회사(`Docker`)의 점(`.`) 도커데스크탑(`DockerDesktop`) |

> 💡 **주의**: 설치가 끝난 뒤에는 **컴퓨터 재부팅(또는 에디터 껐다 켜기)**을 한 번 해야 터미널이 새로 깔린 무전기(`kubectl`)를 인식합니다!

---

### 방법 B. 웹사이트에서 설치 파일 다운로드해서 깔기 (익숙한 방식)
1. 인터넷 브라우저에서 **[Docker 공식 다운로드 페이지](https://www.docker.com/products/docker-desktop/)** 에 접속합니다.
2. 파란색 **[Download for Windows - AMD64]** 버튼을 눌러 설치 파일을 받습니다.
3. 설치 파일을 실행하고 **[OK]**를 눌러 설치한 뒤, 바탕화면에 생긴 **고래 모양 아이콘(Docker Desktop)**을 실행합니다.

---

## ☸️ 4단계: 도커 데스크탑 안에서 '쿠버네티스 스위치' 켜기! (가장 중요 ⭐)

Docker Desktop을 설치하고 실행하셨다면, 마지막으로 **쿠버네티스 기능 스위치**를 켜줘야 합니다. (기본값은 꺼져 있어요!)

1. **Docker Desktop** 프로그램 창을 엽니다. (회원가입/로그인 창이 뜨면 오른쪽 위의 `Skip` 또는 `Continue without signing in`을 눌러 건너뛰셔도 됩니다!)
2. 오른쪽 맨 위 **⚙️ 톱니바퀴 아이콘 (Settings / 설정)**을 클릭합니다.
3. 왼쪽 메뉴 목록에서 **`Kubernetes` (쿠버네티스)**를 클릭합니다.
4. **`[v] Enable Kubernetes` (쿠버네티스 활성화)** 네모 칸에 체크(✔️)합니다!
   - *(만약 Kubeadm과 Kind 중 고르라는 옵션이 보이면 기본값인 `kubeadm` 그대로 두시면 됩니다.)*
5. 오른쪽 아래 파란색 **`[Apply & restart]` (적용 및 재시작)** 버튼을 누릅니다.
6. 왼쪽 아래에 쿠버네티스 아이콘이 **초록색 불(`Kubernetes running`)**로 바뀔 때까지 2~3분 정도 기다리면 **평생 쓸 나만의 쿠버네티스 실습장 완성**입니다!

---

## ✅ 5단계: 잘 깔렸는지 최종 확인하기

설치가 끝났다면 **지금 보고 계신 에디터 프로그램을 한 번 완전히 껐다가 다시 켜신 뒤** (새로 깔린 무전기를 인식시키기 위해 꼭 필요합니다!), 터미널에 다시 아래 명령어를 쳐보세요:

> `.` `/` `c` `h` `e` `c` `k`

모두 초록색 체크 표시가 뜨면 완벽하게 준비 완료입니다!
