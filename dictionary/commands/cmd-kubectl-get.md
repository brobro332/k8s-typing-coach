# 🔍 `kubectl get` : 쿠버네티스에서 가장 많이 쓰는 마법의 단어!

## 1. 무슨 뜻인가요?
영어 동사 **`get` (가져오다 / 보여주다)** 그대로입니다!
쿠버네티스 지배인에게 **"지금 있는 목록 좀 표로 깔끔하게 가져와 봐!"**라고 시킬 때 씁니다.
실무자들이 하루에 치는 명령어의 **절반 이상이 `kubectl get ...`** 일 정도로 가장 중요한 핵심 동사입니다.

## 2. 어순 공식
> **`kubectl`** (지배인아) + **`get`** (목록 가져와라) + **`[보고 싶은 대상]`**

* `kubectl get nodes` : 현재 컴퓨터(노드) 목록 가져와라!
* `kubectl get pods` : 현재 방(파드) 목록 가져와라!
* `kubectl get all` : 지금 떠 있는 거 전부 다 가져와라!

## 3. 꿀팁 옵션: `-o wide` ("더 넓고 자세하게 보여줘!")
그냥 `kubectl get nodes`라고 치면 기본 정보 5개(이름, 상태, 역할, 나이, 버전)만 딱 요약해서 보여줍니다.
여기에 뒤에 **`-o wide`** 를 붙이면?
* **`-o`** : Output (출력 형식)의 약자!
* **`wide`** : 넓게! (IP 주소, 운영체제 종류 등 숨겨진 상세 열까지 옆으로 넓게 펼쳐서 보여줍니다!)
