# 🏢 클러스터 (Cluster)란 무엇인가요?

## 1. 걸음마 비유 (Lv.1 : 프랜차이즈 식당 지점 전체)
단어 뜻 그대로 번역하면 **'무리', '모임', '송이(포도송이)'**라는 뜻입니다.
컴퓨터 1대만으로는 손님 100만 명을 감당할 수 없겠죠? 그래서 **여러 대의 컴퓨터를 하나로 끈끈하게 묶어서 마치 '거대한 슈퍼컴퓨터 1대'처럼 일하게 만든 묶음**을 **클러스터(Cluster)**라고 부릅니다!

식당으로 비유하면, 총괄 지배인(쿠버네티스)이 관리하는 **'강남 본점 식당 전체'**가 바로 하나의 클러스터입니다.

## 2. 실습 핵심 원리 (Lv.2 : 작동 방식)
- 쿠버네티스 클러스터 안에는 크게 두 종류의 직원이 있습니다:
  1. **컨트롤 플레인 (Control Plane, 옛날 말로 마스터 노드)**: 지배인이 앉아서 명령을 내리는 **'사장실/상황실'**
  2. **워커 노드 (Worker Node)**: 실제로 밀키트 요리사(컨테이너)들이 배치되어 땀 흘려 요리하는 **'주방 작업대'**
- 지금 우리가 내 컴퓨터(Docker Desktop)에 켠 미니 쿠버네티스는 연습용이라서 **사장실과 주방 작업대가 내 컴퓨터 1대 안에 합쳐져 있는 '1인용 미니 클러스터'**입니다!

## 3. 실무/면접용 정의 (Lv.3 : 아키텍처)
- 컨테이너화된 애플리케이션을 실행하는 노드(Node)라고 불리는 워커 머신들의 집합입니다. 모든 클러스터는 최소 하나 이상의 워커 노드와 클러스터 상태를 관리하는 컨트롤 플레인(API Server, etcd, Scheduler, Controller Manager)으로 구성됩니다.
