# 💿 이미지 (Image)란 무엇인가요? (그리고 `nginx`가 뭔가요?)

## 1. 걸음마 비유 (Lv.1 : 요리사를 찍어내는 '레시피 붕어빵 틀 / 밀키트 원본')
파드(1인용 방)를 지었으면, 그 안에 **어떤 종류의 요리사**를 넣을지 골라야겠죠?
- 손님에게 웹페이지를 보여주는 **'웹 서버 요리사(`nginx`)'**를 넣을 수도 있고,
- 데이터를 저장하는 **'장부 정리 요리사(`mysql`)'**를 넣을 수도 있습니다.

이때 전 세계 개발자들이 미리 만들어서 인터넷 창고(Docker Hub)에 올려둔 **'요리사 원본 설계도 파일'**을 **이미지(Image)**라고 부릅니다!
우리가 명령어로 **`--image=nginx`**라고 치면, 쿠버네티스 지배인이 인터넷 창고에서 **`nginx`(엔진엑스)** 설계도를 자동으로 다운로드(Pull)해서 방(Pod) 안에 요리사를 짠! 하고 탄생시킵니다.

## 2. 실습 단골 손님: `nginx` (엔진엑스)가 뭔가요?
- 전 세계에서 가장 많이 쓰이는 **초경량 웹 서버 프로그램** 이름입니다!
- 크기가 아주 작고(몇 초 만에 다운로드됨) 켜자마자 **"Welcome to nginx!"**라는 환영 홈페이지를 바로 띄워주기 때문에, 쿠버네티스 실습할 때 **1번 타자 연습용 요리사**로 항상 등장합니다.
- 읽을 때는 **"엔진-엑스"**라고 읽고, 칠 때는 **`n-g-i-n-x`** (5글자)를 칩니다!

## 3. 실무/면접용 정의 (Lv.3 : 아키텍처)
- 컨테이너를 실행하기 위해 필요한 실행 파일, 라이브러리, 환경 변수, 설정 파일 등을 계층적(Layered) 읽기 전용 파일 시스템으로 패키징한 불변(Immutable) 템플릿입니다.
